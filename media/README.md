# media/

Drop your real photos and hero video here, then list them in `salon.js`:

```js
heroVideo: "hero.mp4",                 // short muted loop, ~5–10s, under 5 MB
heroPoster: "hero-poster.jpg",         // optional still shown while the video loads
photos: ["nails-1.jpg", "nails-2.jpg"] // bare file names are looked up in media/
```
